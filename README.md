# 🎤 Smart Voice Assistant

Умный голосовой помощник на Python 3.9 с распознаванием речи и синтезом голоса. Работает полностью оффлайн (кроме опционального API погоды и Википедии).

Поддерживает команды на русском языке: приветствие, время, дата, погода, поиск в Википедии, шутки и завершение работы.

## ✨ Возможности

- Распознавание речи через микрофон (Google Speech Recognition)
- Синтез речи (pyttsx3 — работает оффлайн)
- Определение намерений (intent) по ключевым словам
- Поиск информации в Википедии
- Прогноз погоды (можно использовать реальный API или упрощённый режим)
- Рассказывает шутки
- Полностью настраиваемый через `config.ini` и `responses.json`
- Поддержка Docker
